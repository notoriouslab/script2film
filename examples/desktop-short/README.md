# Template: Claude Code Desktop in 35 seconds

A tutorial hosted by a comic avatar instead of a talking host: six narration lines, the app steps drawn by code,
and 阿華 (a made-up character) peeking in. The sticker pack in `avatar/ahua/` is shared by both languages. No account
needed.

| Language | Folder | Paste to your agent |
|---|---|---|
| English | `en/` | Follow the docs and make examples/desktop-short/en into a film. |
| 中文 | `zh/` | 照文件把 examples/desktop-short/zh 做成片 |

Each folder is a complete project with its own README.
