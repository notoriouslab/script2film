# Template: the 60/40 portfolio (finance explainer, talking host)

Paste this sentence to your agent:

```
Follow the docs and make examples/stock-bond/en into a film.
```

A finance explainer of seven narration lines, about 40 seconds: every chart is drawn by code, and the host sits in a
lower-left circle for the first two lines and fills the screen for the last. The host is a made-up person generated by
AI, and the voice is a synthetic voice designed from a text description, not any real person. The premade pack holds
the narration and the host clips, so no account is needed.

## Two ways

### The quick way: use the premade narration and host (no TalkingPhotos account)

```
python3 tools/examples/fetch_premade.py examples/stock-bond/en
cp -R examples/stock-bond/en/premade/. examples/stock-bond/en/
python3 skills/ve-director/doc/scripts/doc_lint.py examples/stock-bond/en/doc.json
python3 skills/ve-director/doc/scripts/doc_align.py examples/stock-bond/en/doc.json
python3 skills/ve-director/doc/scripts/doc_lint.py examples/stock-bond/en/doc.json --beats examples/stock-bond/en/beats.json
python3 skills/ve-director/doc/scripts/doc_code.py examples/stock-bond/en/doc.json --render
python3 skills/ve-director/doc/scripts/doc_host.py join examples/stock-bond/en/doc.json
python3 skills/ve-director/doc/scripts/doc_cut.py examples/stock-bond/en/doc.json --render
python3 tools/nightly/check.py examples/stock-bond/en/doc.json examples/stock-bond/en/cut_lecture-finance/output.mp4
```

- The first line downloads the narration and host clips from the GitHub Release, checks them against the SHA-256 in
  `premade.json` and unpacks them into `premade/`. If the download fails it prints the release page and the commands
  to unpack by hand.
- **Do not run F2 (voicing).** The host lip-syncs to the premade narration; after a new voicing the lips and the length
  no longer match, and the host has to be made again.
- Run `doc_host.py join` after the timing step (`doc_align.py`): it uses the narration that step writes.

### The full way: your own topic, your own host

Follow `docs/FLOW.md` from F0 to F6, plus optional step B (host).

- The host's look is `refs/host_look.jpg`. To use someone else, make candidates by the rules in optional step B, "The
  look image", pick one, then upload it; a new host needs a voice to match (`refs/voice_cast.json` is the description
  the voice was designed from).
- After changing the look image, move `pip.crop` in `doc.json` until the circle frames the face.
- Spoken numbers are written out in `"tts"` while the subtitles show digits (`60/40`, `14%`); the pictures appear on
  those digits (`sub_at`). Change both together, and update `facts.md` with the source.

## What you will see when it is done

- `cut_lecture-finance/output.mp4`: the film, its length inside the `seconds` range of `expected.json`.
- Cover "The 60/40 Portfolio" with the host in the lower-left circle → the 60/40 pie (the circle ends here) → −37%
  → stocks and bonds in 2008 → both falling in 2022 → "never lose" struck out and rewritten → the host full screen
  with the source.
- The F6 check exits with 0.

Everything the run makes is in `.gitignore`. To clear it: `git clean -ndX examples/stock-bond/en` (look first),
`git clean -fdX examples/stock-bond/en` (delete).

## Files

| File | What it is |
|---|---|
| `doc.json` | seven narration lines, seven beats, the `lecture-finance` palette, the circle crop `pip.crop` |
| `facts.md` | where every number comes from (Damodaran's historical returns data, NYU Stern) |
| `refs/host_look.jpg` | the host's look (AI-generated, not a real person) |
| `refs/narrator.wav`, `refs/narrator.txt` | the reference voice: a synthetic voice designed from a text description (`refs/voice_cast.json`) |
| `premade.json` | where the premade narration and host clips are, their SHA-256 and size |
| `expected.json` | what a right result looks like: beats, lines, length range, narration fingerprint |

The Chinese version is in `examples/stock-bond/zh`. This is not investment advice.
