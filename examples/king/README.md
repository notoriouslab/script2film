# Template: an engineer wakes up as the King of France

A short comedy with no narrator: eight lip-synced shots of two made-up characters, subtitles and a light-jazz score.
The shots are premade, so no VideoExpress account is needed. `plan.md` and `facts.md` are shared by both languages.

| Language | Folder | Paste to your agent |
|---|---|---|
| English | `en/` | Follow the docs and make examples/king/en into a film. |
| 中文 | `zh/` | 照文件把 examples/king/zh 做成片 |

Each folder is a complete project with its own README.
